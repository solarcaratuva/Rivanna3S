## Importing STM's Autogenerated Peripheral Files (e.g. adc.c, fdcan.c, i2c.c, etc.)
Use our importer.py script to that generates files from STM's Autogenerated Peripheral Files.

STM's Autogenerated Peripheral Files are generated using STM32CubeIDE. You need a STM project in STM32CubeIDE that is for the STM board you are planning to upload to. Then, configure the .ioc file of the STM project according the peripheral specs that you desire.

Note that, for the seperate peripheral .c files to be generated, in the .ioc file:
Go to Project Manager
Go to Code Generator
Enable Generate peripheral initialization as a pair of '.c/.h' files per peripheral

The peripheral files that the importer expects:
adc.c
fdcan.c
i2c1.c
i2c2.c
i2c3.c
spi.c
STM32..._FLASH.ID

i2c1.c, i2c2.c, and i2c3.c are i2c.c files that were generated with the i2c peripheral set to different baudrates. 
More specifically, you will need to set/change the baudrates of the i2c peripheral in the .ioc file and regenerate them 3 times, then rename each file accordingly.
The baudrate to i2c#.c file name is as follows:
100000 Hz -> i2c1.c
400000 Hz -> i2c2.c
1000000 Hz -> i2c3.c

Place all generated STM files in a directory (this will be the source directory).

Then run importer.py, filling in the directory path to importer.py and path to src_dir and dst_dir (relative to your current working directory):
python .path\to\importer.py src_dir dst_dir
